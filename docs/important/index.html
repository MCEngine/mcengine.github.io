Contributing & Feedback

  • Anyone can contribute by suggesting features for the main plugin or ideas for extensions.
  • I also welcome suggestions for code improvements or bug fixes.

Open-Core Policy

  • This project follows an Open-Core model.
  • The core plugin will always be MIT Open Source, while extensions may be free or paid.

Support

  • Donations are optional.
  • While I appreciate direct support, purchasing paid extensions is the recommended way to support the project.

Note on AI Usage

  • I use AI to write code efficiently, but the core ideas and architectural structure are entirely my own design.
  • You are welcome to use AI to reference this code for speed.
  • However, I suggest always reading through any AI-generated code.
  • While it often compiles correctly, it is good practice to verify the logic yourself.
Thank you.
