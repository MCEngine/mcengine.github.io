v0.1.0

2026-07-20

Adds release and rate-limit reads, full tag pagination, a configurable timeout, and typed error handling to the gitlab module.

Added New API

  • getAllTags() — returns every tag as a CompletableFuture<List<GitLabTag>>, following the Link header across pages.
  • getLatestRelease() with the read-only GitLabRelease interface (getName(), getTagName(), getBody()).
  • getRateLimit() with the read-only GitLabRateLimit interface (getLimit(), getRemaining(), getReset()), read from the RateLimit-* response headers.
  • Optional Duration constructor argument to configure the HTTP timeout (default 30 seconds).

Changed API refinements

  • Renamed CompareVersion(String) to compareVersion(String) to follow Java naming conventions.
  • Tag reads now follow pagination, so getLatestTag(), getTag(String), and compareVersion(String) search the full tag set rather than only the first 100.
  • Non-success responses other than 404 now throw GitLabApiException, which exposes the HTTP status code and response body, replacing the generic IllegalStateException.

Notes Build & constraints

  • Java 21 toolchain, built with Gradle (Groovy DSL).
  • Still no third-party dependencies; only the Java Platform.
  • Migration: update calls from CompareVersion to compareVersion.
