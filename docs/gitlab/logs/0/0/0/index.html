v0.0.0

2026-07-19

Initial release of the gitlab module.

Added Platform API

  • GitLabPlatform — the single source-of-truth class consumers import.
  • getLatestTag(), getTag(String), and CompareVersion(String), each returning a CompletableFuture.
  • GitLabTag read-only interface (getName(), getCommitSha()).

Notes Build & constraints

  • Java 21 toolchain, built with Gradle (Groovy DSL).
  • No third-party dependencies; only the Java Platform.
  • Addresses the GitLab project by its URL-encoded path; authenticates with the PRIVATE-TOKEN header.
  • Published to GitHub Packages using GITHUB_ACTOR / GITHUB_TOKEN.
